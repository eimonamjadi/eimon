Calculus of a Linear Neuron

A neural network learns by walking downhill on its own error. Three ideas from calculus explain that walk: the derivative, the chain rule and the gradient. This page builds each one on a single neuron, and every figure responds when you drag, slide or press.

Part 1

A neuron is a line

A linear neuron takes a number x, multiplies it by a weight w, and adds a bias b. The result is its prediction, written ŷ and read “y-hat”.

ŷ = wx + b

Plot ŷ against x and you get a straight line. The weight is the slope: each step of 1 in x changes ŷ by w. The bias is the height where the line crosses x = 0. Training means choosing w and b so the line runs close to the data.

Fitting by eye works for two knobs and six points. A real network has millions of weights, so it needs a number that says how wrong the line is, and a rule for which way to turn each knob. Calculus supplies both. The rest of the page uses these same six points, so if you move them, every later figure follows.

Part 2

Measuring the error

For each data point (xi, yi), the neuron predicts ŷi = wxi + b. The gap between the prediction and the truth is the error:

ei = ŷi − yi

Some errors are positive and some are negative, so adding them up would let them cancel. Instead we square each error and take the average. This number is the mean squared error, and it is the neuron’s loss:

L(w, b) = 1n Σi (wxi + b − yi)2

Switch the figure to squares. Each error becomes a real square with area ei2, and the loss is the average area. Training shrinks the squares.

Key ideaThe data is fixed. Only w and b move. So the loss is a function of the two knobs, and training is the search for the knob settings where that function is smallest.

Part 3

The derivative

Freeze b for a moment. The loss then depends on w alone, and you can draw it as a curve. For a linear neuron with squared error, that curve is always a parabola: a bowl with one lowest point.

Training asks one question over and over. If I nudge w, does the loss go up or down, and how fast? Pick two points on the curve a distance h apart. The slope of the line through them, rise over run, is

secant slope = L(w + h) − L(w)h

Now shrink h. The two points merge, and the secant line turns into the tangent line, which just touches the curve. Its slope is the derivative:

dLdw = limh→0 L(w + h) − L(w)h

The sign of the derivative tells you which way is downhill, and its size tells you how steep the hill is.

dL/dw > 0

Loss rises as w grows. Lower w.

dL/dw < 0

Loss falls as w grows. Raise w.

dL/dw = 0

Flat ground: the bottom of the bowl, the best w for this b.

The derivative also predicts change. For a small nudge Δw, the loss changes by about (dL/dw) × Δw. That one approximation is what every training step relies on.

Check yourself

At the current w, dL/dw = −4. You raise w by 0.01. About how does the loss change?

Part 4

Derivative rules

Taking a limit every time would be slow. A handful of rules give exact derivatives in one line, and four of them cover everything a linear neuron needs.

RuleFormulaExample
Constant(c)′ = 0(7)′ = 0
Power(xn)′ = nxn−1(x3)′ = 3x2
Constant multiple(c·f)′ = c·f′(5x2)′ = 10x
Sum(f + g)′ = f′ + g′(x2 + 3x)′ = 2x + 3

Apply the power rule to one squared error, e2, and you get 2e. Big errors push back hard; small errors push gently; zero error pushes not at all. The last preset above, (x − 2)2, is exactly a squared error with target 2.

Part 5

The chain rule

The loss never touches w directly. The weight changes the prediction, the prediction changes the error, and the error changes the loss. Each link is easy on its own. The chain rule says the slope of the whole chain is the product of the slopes of its links:

∂L∂w = ∂L∂e · ∂e∂ŷ · ∂ŷ∂w = 2e · 1 · x

The curly ∂ means the same derivative as in part 3, taken while every other input stays still. Working backward from the loss to the weights, link by link, is called backpropagation. Step through it for one data point.

A derivative is a prediction, so you can test it. Nudge w by Δ, measure how much the loss for this point really changes, and compare that with what ∂L/∂w × Δ predicted.

The whole-dataset loss is an average of per-point losses, and the derivative of an average is the average of the derivatives. So for all n points at once:

∂L∂w = 2n Σi eixi∂L∂b = 2n Σi ei

Part 6

The gradient

With two knobs, the loss is a surface over the (w, b) plane. The map below shows it from above. Stronger color means higher loss, and the bowl’s bottom is the best fit.

A partial derivative turns one knob and holds the other still. ∂L/∂w is the slope of the slice you get by walking left to right through your point. ∂L/∂b is the slope of the slice walking bottom to top. Stack both into a vector and you have the gradient:

∇L = ( ∂L∂w , ∂L∂b )

The gradient points uphill, in the direction where the loss rises fastest. So its negative, −∇L, points straight downhill.

The ellipses are contours: every point on one has the same loss. The gradient always crosses them at a right angle, because moving along a contour leaves the loss unchanged.

Check yourself

At some point the gradient is ∇L = (3, −1). Which way should (w, b) move to lower the loss?

Part 7

Gradient descent

Now put the pieces together. Start anywhere. Compute the gradient. Take a small step against it. Repeat. That loop is gradient descent, and it is how neural networks are trained.

w ← w − η ∂L∂wb ← b − η ∂L∂b

The learning rate η (eta) sets the step size. Too small and training crawls. Too large and each step overshoots the valley and lands higher on the far side, until the loss explodes. For a bowl like this one there is an exact limit: η must stay below 2 divided by the bowl’s steepest curvature. The red mark on the slider shows that limit for your current data.

Try the presets. Tiny steps creep along the valley floor. Smooth steps glide to the bottom. Near the limit, each step jumps across the valley and back, and the loss curve wobbles as it falls. Past the limit, the jumps grow and the loss shoots up.

Part 8

Many inputs, same calculus

Real neurons take many inputs, and each input gets its own weight:

ŷ = w1x1 + w2x2 + w3x3 + b

The chain rule doesn’t change. Each weight’s link to ŷ has slope xj, so

∂L∂wj = 2e · xj

Each weight is blamed in proportion to its own input. Set an input to zero below and watch its weight’s gradient vanish.

With many examples stacked as rows of a matrix X and their errors in a vector e, all the weight gradients come out of one formula. It is the same expression a deep learning library computes for every linear layer:

∇wL = 2n X⊤e

Stack two linear layers with nothing in between and you still have one line: W2(W1x) = (W2W1)x. Each extra layer adds one link to the chain, and backpropagation multiplies through it exactly as in part 5. Real networks put a nonlinear function between layers so they can bend, and the chain rule handles that link too.

Summary

Everything on one card

Model

ŷ = wx + b

A linear neuron draws a line. w is its slope, b its height at x = 0.

Loss

L = 1nΣ(ŷi − yi)2

The average squared error. Zero only when every point sits on the line.

Derivative

ΔL ≈ dLdw Δw

How fast the loss changes as you nudge w. The sign says which way is downhill.

Chain rule

∂L∂w = ∂L∂ŷ · ∂ŷ∂w

Multiply the local slopes along the path from w to L.

Gradient

∂L∂w = 2nΣeixi

Each weight is blamed by the error times its input. For b, drop the xi.

Update

w ← w − η ∂L∂w

Step against the gradient. Keep η below the limit or the steps blow up.
